Astuce du jour

Une astuce, appliquée tout de suite

Astuces PC

Retrouver un fichier en deux secondes

Appuyez sur la touche Windows et tapez le nom du fichier. La recherche s'ouvre instantanément, sans ouvrir l'explorateur.

Dépannage

Fermer un programme qui ne répond plus

Ctrl + Maj + Échap ouvre le gestionnaire des tâches : sélectionnez le programme bloqué puis cliquez sur Fin de tâche.

Sécurité

Enregistrer un mot de passe solide

Utilisez une phrase de passe de quatre mots sans lien entre eux, puis ajoutez un chiffre et un symbole. Facile à retenir, très difficile à deviner.

Organisation

Nommer ses fichiers pour les retrouver

Adoptez la forme 2026-03-14_facture_electricite. La date en tête de nom trie automatiquement vos documents dans le bon ordre.

Entretien

Vérifier l'espace disque restant

Ouvrez Ce PC dans l'explorateur : la barre sous chaque disque indique l'espace libre. Sous 10 % restants, pensez à faire du tri.

⌨️ Raccourcis indispensables

  • Ctrl + CCopier la sélection
  • Ctrl + VColler
  • Ctrl + ZAnnuler la dernière action
  • Alt + TabChanger de fenêtre
  • Windows + DAfficher le bureau
  • Windows + EOuvrir l'explorateur de fichiers
  • Windows + LVerrouiller l'ordinateur
  • Ctrl + Maj + ÉchapOuvrir le gestionnaire des tâches
