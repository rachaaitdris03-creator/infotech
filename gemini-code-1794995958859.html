Comprendre sa machine

Les bases de l'informatique, sans jargon

Quatre piliers pour comprendre ce qui se passe derrière votre écran.

1. Le Matériel (Hardware)

Processeur (CPU) : le cerveau qui exécute les calculs.
Mémoire vive (RAM) : le bureau temporaire où s'ouvrent vos logiciels.
Stockage (SSD) : l'armoire où vos fichiers restent enregistrés.

2. Le Système d'exploitation (OS)

Windows, macOS ou Linux : c'est le chef d'orchestre qui fait le lien entre vous, vos logiciels et les composants matériels de l'ordinateur.

3. Internet et le Web

Internet est le réseau mondial de câbles et de serveurs. Le Web est l'ensemble des pages que vous consultez via un navigateur (Chrome, Firefox, Edge).
